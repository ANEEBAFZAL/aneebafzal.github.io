# aneebafzal.github.io

Personal portfolio of **Aneeb Afzal**, SecOps Engineer and SOC operations specialist based in Doha, Qatar.

🔗 **Live site:** https://aneebafzal.github.io

## Stack

A static site with no build step and no dependencies:

- `index.html`: page structure
- `style.css`: styles and animations
- `main.js`: content (the `ME` object at the top) and interactivity

## Security

- Strict Content Security Policy: no inline scripts or styles, and scripts only from this origin
- No third-party scripts, trackers, cookies or forms
- Visitor input in the terminal is HTML-escaped; links are restricted to `https:`, `mailto:` and relative URLs
- Served over HTTPS by GitHub Pages

## Updating

Edit the `ME` object at the top of `main.js` and commit. GitHub Pages redeploys automatically.
